- Implemented administrative approval and rejection flows with payment-status tracking.
- Integrated PostgreSQL persistence, authentication, and reusable payment details.

### 2. ChemSAGE — Chemistry Department Portal
**Next.js · Tailwind CSS · Supabase · PostgreSQL**

A student portal designed for the Chemistry Department at IIT Madras.

- Implemented restricted student registration with administrator approval.
- Integrated real-time messaging, direct messages, and topic-based study groups.
- Developed academic resource sharing, past-exam archives, a weekly timetable, and a task board.

### 3. Local LAN Messenger
**Python · FastAPI · WebSockets · WebRTC · SQLite**

A cross-platform messaging application designed for communication over a local network without requiring internet access.

- Implemented real-time messaging and file sharing.
- Added WebRTC-based voice and video calling.
- Developed LAN IP detection, HTTPS startup scripts, and organized media storage.

[View repository](https://github.com/nixhudxhiya927/Local-LAN-Messenger)

### 4. NovaNews — AI-Powered News Summarizer
**React · Node.js · Express · Supabase · Gemma**

A full-stack news application that combines article aggregation with AI-generated summaries.

- Integrated NewsAPI for retrieving headlines, searching articles, and filtering by category.
- Built an AI summarization endpoint for generating concise article summaries.
- Implemented user authentication and a persistent article-bookmarking library.

### 5. Industrial Billing Suite
**PHP · MySQL · Apache · JavaScript · FPDF**

An invoice and inventory management application built to automate a practical billing workflow.

- Implemented customer and product management, stock tracking, and invoice history.
- Automated GST calculations for applicable CGST/SGST and IGST cases.
- Added session-based authentication, transactional invoice saving, and PDF generation.

### 6. Workspace Rental Price Tier Prediction
**Python · pandas · scikit-learn · LightGBM · XGBoost · CatBoost**

An ongoing Kaggle machine-learning project predicting workspace rental price tiers from tabular listing data.

- Performed exploratory data analysis, feature engineering, categorical encoding, and missing-value treatment.
- Evaluated multiple classification models using stratified validation and hyperparameter tuning.
- Experimented with probability-based ensembling and class-wise prediction calibration.

**Best visible submission score:** 0.71731

[View Kaggle competition](https://www.kaggle.com/competitions/167481)
